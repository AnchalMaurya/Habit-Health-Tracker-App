# 🧘‍♀️ Habit & Health Tracker Project

A simple yet effective **Habit and Health Tracker** built using **HTML, CSS, and JavaScript**.  
This app helps users build positive habits, track their daily activities, and visualize their progress — all within the browser using local storage.

---

## 🚀 Features

### 🌿 Habit Management
- Add and delete daily habits  
- Mark habits as completed or pending  
- Automatically save progress in local storage  

### 💪 Health Tracking
- Track key health activities (e.g., exercise, water intake, sleep hours)  
- Calculate BMI

### 🎨 User Interface
- Fully responsive layout built with HTML & CSS  
- Simple and elegant dashboard UI  
- Interactive animations and hover effects  

### ⚡ Data Handling
- All data stored locally using `localStorage`  
- Dynamic DOM updates using JavaScript

## 🧠 How It Works
index.html
The landing page where users can add habits and view a summary

Connected to style.css for styling and script.js for logic

dashboard.html
Displays user’s tracked habits and progress visually

Uses dashboard.css for design and dashboard.js for interaction

localStorage
Stores user habits and progress

Persists data even after page reload
